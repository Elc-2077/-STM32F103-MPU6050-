# STM32F103C8T6 姿态仪 / 水平仪

基于 MPU6050 和 0.96" OLED（SSD1306）的双模姿态显示。竖直握持时是飞机式人工地平仪，平放时自动切换成气泡水平仪。

核心是一套三级滤波 + 互补滤波姿态解算，解决了直接用加速度计算角度的高频抖动问题。

## 功能

**竖直模式（VERT）** — 人工地平仪
- 地平线随横滚旋转、随俯仰平移，圆形表盘内裁剪
- 地面侧网点填充，天空侧留空
- 俯仰刻度梯（±10° / ±20°）、固定倾角刻度（0 / ±30° / ±60°）
- 随横滚转动的三角指针，固定机翼符号
- 右侧数显俯仰 / 横滚 / 偏离竖直的总倾角，精度 0.1°

**平放模式（LEVL）** — 气泡水平仪
- 小球往低处滚，带居中容差圈和十字线
- 右侧数显 X / Y 倾角和偏离水平面的总倾角

两个模式按重力方向自动切换，带回差（`FLAT_ENTER` / `FLAT_EXIT`）防止临界点反复跳。

## 接线

两条 I2C 总线独立，互不阻塞。

| 器件 | 信号 | 引脚 | 方式 |
|------|------|------|------|
| OLED | SCL | PB8 | 软件 I2C |
| OLED | SDA | PB9 | 软件 I2C |
| MPU6050 | SCL | PB10 | 硬件 I2C2 |
| MPU6050 | SDA | PB11 | 硬件 I2C2 |

供电 3.3V。板载 LED 在 PC13，开机时用闪烁次数指示 I2C 扫描和初始化结果。

OLED 地址默认 `0x78`（SA0 接地），SA0 接 VCC 的模块改 `OLED.h` 里的 `OLED_ADDRESS` 为 `0x7A`。

## 姿态解算

```
MPU6050 原始数据
  ├─ 硬件 DLPF（44Hz）           抗高频抖动第一级
  ├─ 5 点中值滤波                剔除 I2C 误码和机械冲击的单点尖峰
  ├─ 轴向重映射                  适配实际安装方向
  ├─ 加速度一阶低通（20ms）      去残余噪声
  ├─ 互补滤波                    陀螺仪给高频、加速度给低频
  │   ├─ 欧拉角速度投影          按真实运动学，不是固定轴映射
  │   ├─ 加速度自适应可信度      甩动时不被线加速度拽歪
  │   └─ 陀螺仪零偏在线估计      温漂自动跟掉
  └─ 显示回差取整                消除末位数字跳动
```

采样 200Hz，显示刷新 20Hz。

### 欧拉角速度投影

陀螺仪测的是机体角速度，要转成欧拉角速度。常见写法直接用 `dp/dt = -wx`、`dr/dt = wz`，但这只在俯仰和横滚都为零时成立，一旦倾斜就串轴，倾得越多误差越大。

天顶向量在世界系固定，在机体系里满足 `du/dt = -ω × u`。代入参数化

```
ux = cos(p)sin(r),  uy = cos(p)cos(r),  uz = sin(p)
```

解得

```
dp/dt = wy·sin(r) - wx·cos(r)
dr/dt = wz - tan(p)·(wx·sin(r) + wy·cos(r))
```

固定映射就是这个式子在 `p=0, r=0` 的特例。`tan(p)` 在 ±90° 发散（万向节锁），但那正好是切平放模式的区域，限幅即可。

### 加速度自适应可信度

加速度计只有在静止时才等于重力。晃动时线加速度混进来，地平线会被拽歪。

按 `|a|` 偏离 1g 的程度动态调整权重：偏离 4% 以内完全可信，25% 以上完全不信（纯陀螺仪外推），中间线性过渡。甩动过程中地平线不再乱跑，停下来自动收敛。

### 陀螺仪零偏在线估计

开机标定只能消掉当时的零偏，温漂跟不了。稳态下角度误差正比于残余零偏，把误差积分回角速度即可持续修正。

只在接近静止（角速度 < 2 dps）且加速度可信时学习，否则会把机动当零偏学进去。积分限幅防饱和。

## 上手校准

**开机标定** — 上电后屏幕显示 `Calibrating / Keep still...`，此时必须静止放置约 1 秒，采陀螺仪零偏。晃动会导致姿态缓慢漂移。

**加速度计零偏（需要实测）** — `Hardware/Attitude.c` 里的 `OFF_AX` / `OFF_AY` / `OFF_AZ` 默认为 0。装夹误差和芯片零偏因板而异，通常带来 1~3° 的静态偏差，**不校准会以为是滤波器有问题**。

测法：板子平放静止，读屏幕上的 X / Y 倾角，偏差 1° 约对应 286 LSB（`16384 × sin1°`），按符号填入对应常数重新编译。

**安装方向** — 若姿态仪动作方向不对，改 `Attitude.c` 顶部的 `UP_X` / `UP_Y` / `UP_Z` 重映射宏。注意成对交换两条轴时要给第三条加负号，否则左右手系翻转，旋转方向会反，陀螺仪还会在互补滤波里和加速度计对着干。

## 可调参数

集中在 `Hardware/Attitude.c` 顶部。

| 参数 | 默认 | 作用 |
|------|------|------|
| `TAU_COMP` | 0.50s | 互补滤波时间常数，越大越稳越迟钝 |
| `TAU_FLAT` | 0.15s | 平放模式低通 |
| `BIAS_GAIN` | 0.03 | 零偏估计收敛速度 |
| `DEV_MIN` / `DEV_MAX` | 0.04 / 0.25 | 加速度可信度门限 |
| `FLAT_ENTER` / `FLAT_EXIT` | 0.80 / 0.65 | 模式切换回差 |

MPU6050 量程在 `MPU6050.c`：陀螺仪 ±500°/s，加速度 ±2g，采样 200Hz，DLPF 44Hz。改量程要同步改 `Attitude.c` 里的 `GYRO_LSB` / `ACC_LSB`。

## 编译

**PlatformIO**

```
pio run -t upload
```

**CMake + arm-none-eabi-gcc**

工具链可以用 STM32CubeIDE 自带的。Windows 上先跑 `setup_env.bat`，它会自动找到 CubeIDE 的安装位置，把 gcc / cmake / ninja / make 加进 PATH 并开一个新命令行窗口。装在非常规位置的话，先设 `CUBEIDE_ROOT` 指向含 `plugins` 的那层目录：

```
set CUBEIDE_ROOT=D:\ST\STM32CubeIDE_1.16.0\STM32CubeIDE
setup_env.bat
```

自己装了 arm-none-eabi-gcc 的话不用管这个脚本，直接：

```
cmake -DCMAKE_TOOLCHAIN_FILE=cubeide-gcc.cmake -S ./ -B Debug -G"Unix Makefiles" -DCMAKE_BUILD_TYPE=Debug
make -C Debug -j
```

目标 STM32F103C8T6，72MHz（8MHz 外部晶振 × 9）。
